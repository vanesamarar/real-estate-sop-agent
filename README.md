# Real Estate Listing Intake & SOP Agent

A Python command-line tool that automates real estate listing intake by checking incoming agent emails against brokerage Standard Operating Procedures (SOPs) using the Gemini API.

## What It Does
- Pulls key property details (address, list price, year built, occupancy, seller info) out of messy intake emails and flags missing required fields.
- Checks those details against a Washington State / NWMLS-style SOP to list required compliance forms (like Form 22J for pre-1978 homes or Managing Broker review for listings over $1M) and cites the exact rule number for each step.
- Determines whether the Salesforce opportunity can move forward or needs to stay on hold due to missing info.
- Drafts ready-to-send scheduling emails for photography and sign installation when occupancy rules allow it.
- Runs an interactive Q&A loop in the terminal so you can ask follow-up questions grounded strictly in the SOP text.

Because internal brokerage SOPs and client emails are private, this prototype uses a sample NWMLS compliance SOP and a simulated intake email. In a live workflow, the structured output could be passed as JSON into Salesforce, Slack, or email drafts.

## Files
- `agent.py` — Main Python script using the `google-genai` SDK (with multi-model fallback handling)
- `sop_listings.txt` — Sample Washington State / NWMLS listing intake SOP
- `agent_email.txt` — Sample incoming listing email from an agent
- `intake_report_output.txt` — Example report generated by the script

## How to Run
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install google-genai
export GEMINI_API_KEY="your_api_key_here"
python agent.py
```
