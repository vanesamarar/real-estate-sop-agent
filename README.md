# Real Estate Listing Intake & SOP Agent

A Python command-line prototype that automates real estate listing intake by checking incoming agent emails against brokerage Standard Operating Procedures (SOPs) using the Gemini API.

## What It Does
1. **Extracts Structured Data:** Parses unstructured listing emails into key-value property fields and flags missing required information (e.g., seller phone number, parcel ID).
2. **Checks Compliance Rules:** Cross-references property details against an NWMLS-style brokerage SOP to identify required forms (e.g., Form 22J for pre-1978 homes, Managing Broker review for listings over $1M) and cites the exact rule number for each action.
3. **Flags CRM Blockers:** Identifies whether a Salesforce opportunity can advance or must be held due to missing intake fields.
4. **Drafts Vendor Emails:** Generates ready-to-send scheduling emails for photography and sign installation when occupancy rules permit.
5. **Interactive SOP Q&A:** Includes a terminal Q&A loop to answer policy questions strictly grounded in the SOP text.

*(Note: Because internal brokerage SOPs and client emails are confidential, this demo uses simulated NWMLS compliance rules and sample intake data. In production, the output can be serialized as JSON to trigger Salesforce updates, Slack alerts, or email drafts automatically.)*

## Files
- `agent.py` — Main Python script calling the `google-genai` SDK
- `sop_listings.txt` — Sample Washington State / NWMLS listing intake SOP
- `agent_email.txt` — Sample incoming listing email from an agent
- `intake_report_output.txt` — Example report generated by the script

## How to Run
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install google-genai
export GEMINI_API_KEY="your_api_key_here"
python agent.py
```
